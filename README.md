## Featured Project

### [Gongnong — AI-powered YouTube to Korean Sign Language](https://github.com/who0oami/Gongnong)

An accessibility service that turns YouTube subtitles and audio into Korean Sign Language avatar videos.

- Built KNN hand-shape correction with **1,500 signs and 216K hand frames**
- Created **18 new consonant avatar assets** missing from the original dataset
- Explored mT5 fine-tuning and Ollama/Qwen for Korean-to-KSL Gloss conversion
- Integrated Vercel, Render, Supabase, Gemini, AWS S3, and FFmpeg
- Reduced a 3-minute video conversion from **33 minutes to 8 minutes 27 seconds**
